# ArainPhoneDeck

Download the latest Windows installer from [Releases](https://github.com/arainsanu/ArainPhoneDeck-Windows-Public/releases/latest).

ArainPhoneDeck turns a phone or tablet into a Windows control deck with Work, Gaming, and Stream modes. It includes OBS controls, favorite scenes, live CPU and RAM indicators, and customizable buttons. The source code is maintained in a private repository.

The GitHub installer includes an animated Luffy dashboard pet. He moves between app tiles, stretches his arms toward icons, laughs after landing, and sleeps after a minute of inactivity. The pet can be turned off in Settings > Layout and backups. The separate [Microsoft Store edition](https://apps.microsoft.com/detail/9PCC81K7ZMZX) is pet-free and is pending certification.

See [the ArainXR website](https://arainxr.in/arainphonedeck/) for setup instructions and feature details.

The GitHub installer is unsigned. Check the SHA-256 checksum in each release before installing; Windows may show a security warning. The Microsoft Store edition follows Microsoft's separate certification and signing process.
